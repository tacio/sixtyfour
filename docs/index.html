A typeface for base64

Sixty four symbols
you can say out loud.

Base64 is text no one can read. aGVsbG8gd29ybGQ cannot be compared at a glance, dictated over a phone, or checked by eye. Sixty Four gives each of the 64 characters a symbol instead — and encodes it twice, once as colour and once as hatch, so it survives a black-and-white printer and colour blindness alike.

Reading one symbol

Shape, then texture.

The symbol p
Shape Flame

Elements, shape 1 of 0–3. Carries the low two bits.

Texture Dots · Blue

Tier 2 of 0–3. Colour and hatch say the same thing, so either one on its own is enough to read it.

Using it

One file, no hosting.

sixty-four.css carries the font inside it as a data URI, so there is no second request and nothing to upload. Link it and add the class.

<link rel="stylesheet" href="sixty-four.css">

<span class="sixty-four">U2l4dHkgRm91ciBtYWtlcyBi</span>

Outside the browser, install SixtyFour-Regular.ttf and set it as the font in any editor or terminal — every glyph is one em wide, so columns stay aligned. Where colour fonts are not supported the same file falls back to the hatched outlines rather than to nothing. Sixty Four Mono ships separately for anywhere that prefers no colour table at all.

URL-safe base64 works too: -, _ map onto the same symbols as + and /, so JWTs and file-safe encodings need no conversion.
